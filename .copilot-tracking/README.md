# Prepared HVE Core fallback

These are curated workshop artifacts, not exported HVE execution logs. Their
layout illustrates Research -> Plan -> Implement -> Review. Generated filenames
and exact output differ by plugin version.

1. [Research](research/low-stock-research.md): evidence from this application.
2. [Plan](plans/low-stock-plan.md): decision, acceptance criteria and steps.
3. [Implementation record](changes/low-stock-changes.md): changed files/commands.
4. [Review](reviews/low-stock-review.md): acceptance mapping and known limitations.

Start a live RPI run from `m3-complete` on your own branch, not from this already
implemented checkpoint. Installing HVE Core is a separate VS Code user action.
No fake HVE plugin or copied third-party agents are bundled here.
